# sverka

Ночная сверка двух выгрузок. Отгрузки против прайса перевозчиков, наряды
против расценок, остатки в CRM против склада. Утром ответственный получает в
Telegram только строки, где цифры не сошлись, и сумму ошибки в рублях.

Работает с тем, что реально отдают 1С, МойСклад и Excel: Windows-1251 и UTF-8
с BOM, точка с запятой или запятая, числа вида `1 234,50`. Только стандартная
библиотека Python 3.10+, ставить ничего не нужно.

## Расценки на перевозку

Слева отгрузки за день из 1С, справа прайс перевозчиков. В отгрузках один
маршрут повторяется много раз, поэтому прайс сверяется как справочник
(`--spravochnik`): повторы слева нормальны, а строки прайса, по которым не
было рейсов, ошибкой не считаются.

```
$ python -m sverka primery/rascenki/otgruzki.csv primery/rascenki/prais.csv \
    --kluch Перевозчик --kluch "Маршрут=Направление" \
    --sravnit "Расценка=Цена за тонну" --spravochnik \
    --kolichestvo Тоннаж --pokazat "Номер,Дата,Перевозчик" \
    --nazvanie "Расценки на перевозку за 14-16.10"

Расценки на перевозку за 14-16.10: найдено расхождений 3
Разница в деньгах: 2 074,00 ₽
• ОТ-1185, 15.10.2026, Гранит-Авто: Расценка 680, в «prais.csv» 610 (1 386,00 ₽)
• ОТ-1188, 16.10.2026, ТрансВолга: Расценка 560, в «prais.csv» 520 (688,00 ₽)
• ОТ-1187, 15.10.2026, СамараЛогистик: нет в «prais.csv»
```

Последняя строка важнее первых двух: перевозчика нет в прайсе, значит
расценку на рейс кто-то поставил руками.

## Остатки: CRM и МойСклад

Обе стороны равноправны, поэтому ловятся и разные цифры, и товары, которые
есть только в одной системе.

```
$ python -m sverka primery/ostatki/crm.csv primery/ostatki/moysklad.csv \
    --kluch "Артикул=Код" --sravnit "Остаток=Доступно" \
    --pokazat "Артикул,Наименование" --nazvanie "Остатки CRM и МойСклад"

Остатки CRM и МойСклад: найдено расхождений 4
• К-1002, Кофе молотый 250 г: Остаток 120, в «moysklad.csv» 96
• С-3001, Сироп ваниль 1 л: Остаток 12, в «moysklad.csv» 0
• Ч-2002, Чай зелёный 100 пак.: нет в «moysklad.csv»
• С-3002, Сироп карамель 1 л: есть в «moysklad.csv», нет в «crm.csv»
```

Пока такие строки есть, помощнику закупщика рано советовать, что заказывать:
он будет уверенно опираться на неверный остаток.

## В планировщик

Код выхода: `0` расхождений нет, `1` есть, `2` выгрузку нельзя сверять (нет
колонки, пустой файл, в числе текст). Отправка в Telegram только при `1`:

```
TELEGRAM_BOT_TOKEN=... TELEGRAM_CHAT_ID=... \
python -m sverka otgruzki.csv prais.csv ... --telegram --csv rashozhdeniya.csv
```

`--csv` пишет полный список, если в сообщение всё не влезло. `--dopusk 0,5`
пропускает копеечные расхождения от округления.

Ключ сравнивается без учёта регистра и лишних пробелов: «Тольятти  - Самара»
и «тольятти - самара» один маршрут. Повтор ключа в справочнике выводится
отдельной строкой, потому что сверка по такому ключу ненадёжна.
